# PROTECTION CIRCUIT FOR AVO MK3

Protects the AVO MK3 meter movement from overload using diode clamping + a capacitor. 
Shared free (gerbers + schematic) for fellow restorers.

## How It Works
Diodes clamp the voltage across the meter during a fault; the capacitor slows transients so the needle isn't slammed before the clamp kicks in.

## Manufacturing Details
- PCB: 48x39mm, 2-layer
- Mounts: 2x5mm plated holes with 10mm pad
